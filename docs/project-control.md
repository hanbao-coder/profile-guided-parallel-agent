# 项目总控台

最后更新：2026-07-29

## 最终目标

完成一个可复现的本科生科研项目：

> 基于性能剖析与依赖分析的 Python 代码自动并行化 Agent。

最终系统不仅生成并行代码，还必须回答：

1. 代码是否存在不能直接并行的依赖？
2. 任务是否值得并行？
3. 应使用多少 Worker 和多大的任务块？
4. 并行后是否正确、是否真的更快？
5. 如果并行更慢，能否自动优化或回退？
